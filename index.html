    主屏幕壁纸

    当前壁纸 纯色 · 雾蓝

    默认是纯色壁纸。选一个颜色立刻生效；导入图片后会盖在纯色上，恢复默认就回到这里选的颜色。

    水珠样式

    水珠会一直浮在壁纸上方，不受壁纸影响。星星会让雨滴末端变成小小的金色星光。

    提示音

    📤 发送消息 默认音效
    📥 收到消息 默认音效

    支持 mp3 / m4a / wav 等常见格式，建议在 500KB 以内。导入的音效会随聊天记录一起存在浏览器里；换设备不会同步。

    回复

    回复时间会在「最短」和「最长」之间随机取一个值，最长可以拉到 10 分钟；每条回复的字卡数也会在 1 到上限之间随机。来电与转账的「少」大约 30–70 分钟一次，「多」更频繁；改完会立刻按新频率重新计时。朋友圈概率调到 0 就不会再自动发动态。

    塔罗 API

    AI 解牌接口

    兼容 OpenAI 的 /v1/chat/completions 格式。密钥只存在这台设备的浏览器里，不会上传到别处。没配置接口时，塔罗页会用牌面关键词做本地解读。

    如果接口返回 CORS 错误，说明服务端不允许网页直接调用，可以换一个允许跨域的代理地址。

    TA 只会给「是」或「否」，不解释、不折中。问题越具体，这个决定就越好用。结果会以决策卡的形式出现在对话里。
